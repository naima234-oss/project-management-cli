# Project Management CLI Tool

A Python 3.10+ command-line application for managing users, projects, and tasks. Data is stored locally in JSON.

## Features

- Create and list users.
- Create projects owned by users and list projects by user.
- Search projects by title or description.
- Add tasks to projects and assign multiple existing users as contributors.
- Mark tasks as complete.
- Edit project and task titles/descriptions.
- Save data automatically to a JSON file.
- Automated unit tests using Python's `unittest`.

## Setup (Linux/macOS)

```bash
python3 --version
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

The core application uses only Python's standard library. `rich` is included as an optional dependency for future terminal formatting enhancements.

## Run examples

Run commands from the root project directory:

```bash
python main.py add-user --name "Alex" --email "alex@example.com"
python main.py add-user --name "Sam"
python main.py list-users

python main.py add-project --user "Alex" --title "CLI Tool" --description "Project tracking app"
python main.py list-projects
python main.py list-projects --user "Alex"
python main.py search-projects --query "tracking"

python main.py add-task --project "CLI Tool" --title "Implement add-task" --contributors "Alex" "Sam"
python main.py list-tasks --project "CLI Tool"
python main.py complete-task --project "CLI Tool" --title "Implement add-task"

python main.py edit-project --title "CLI Tool" --new-title "Project Tracker"
python main.py edit-task --project "Project Tracker" --title "Implement add-task" --description "Implement and test task creation"
```

Use `python main.py --help` or `python main.py add-task --help` to view help. To use a different JSON file, put `--data /path/to/file.json` immediately after `main.py`, before the subcommand.

## Data relationships

- A `User` owns zero or more `Project` objects.
- A `Project` contains zero or more `Task` objects.
- A `Task` can list multiple user names as contributors.

The data is saved in `data/projects.json` by default. Do not edit this file while the application is running.

## Run tests

```bash
python -m unittest discover -s tests -v
```

## Git workflow

```bash

git commit -m "Initial project management CLI implementation"
git branch -M main
```

Create a public repository on GitHub, then connect and push it using the repository URL shown by GitHub:

```bash
git remote add origin https://github.com/YOUR-USERNAME/project-management-cli.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username. Do not publish passwords, tokens, or private information.

## Limitations / future improvements

This is a local simulated project tracker, not a networked multi-user service. It does not implement passwords or role-based authorization. Potential improvements include admin authentication, deletion commands, richer terminal tables, and CI testing.
